Cẩm Nang Công Thức ADN & Gen Lớp 9 Toàn Tập

Tài liệu ôn thi vào 10 chuyên và đại trà môn Sinh học.

1. Số lượng & % Nu:

• A = T ; G = X
• N = 2A + 2G = 2T + 2X
• %A + %G = 50% = N/2
• %A = (A / N) × 100%

2. Chiều dài & Chu kỳ xoắn:

• L = (N / 2) × 3.4 Å
• 1 nm = 10 Å | 1 µm = 10,000 Å
• C = N / 20 = L / 34
• 1 chu kỳ gồm 10 cặp = 20 Nu

3. Khối lượng & Liên kết:

• M = N × 300 đvC
• H = 2A + 3G (2 lk A-T, 3 lk G-X)
• LK hóa trị giữa các Nu: N - 2
• Tổng LK hóa trị cả gen: 2N - 2

4. Phiên mã & Dịch mã:

• Số Ribônu: rN = N / 2
• Chiều dài mARN = Lgen = rN × 3.4 Å
• Số Codon = rN / 3 = N / 6
• Số axit amin cung cấp: (rN / 3) - 1

5. Tương quan 2 mạch đơn:

• A1 = T2 ; T1 = A2
• G1 = X2 ; X1 = G2
• A = T = A1 + A2 = T1 + T2
• G = X = G1 + G2 = X1 + X2

6. Nhân đôi ADN (k lần):

• Số phân tử ADN con: 2^k
• Nu tự do môi trường cần cung cấp:
  N_mt = N × (2^k - 1)
• A_mt = A × (2^k - 1)
